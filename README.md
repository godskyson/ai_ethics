# AI 윤리 수행평가

학생이 텍스트 분류 모델을 직접 만들어 보고(모델 이름 → 데이터 입력 → 학습 → 테스트), 테스트 결과 3개를 근거로 **개인정보 활용**, **인공지능 편향**, **인공지능 판단**에 관한 주의점을 서술해 제출하는 수행평가 사이트입니다. 교사는 실시간 대시보드로 진행 상황과 화면 이탈을 확인합니다.

| 화면 | 주소 |
|---|---|
| 학생 | https://godskyson.github.io/ai_ethics/ |
| 교사 | https://godskyson.github.io/ai_ethics/teacher.html |

## 수업 당일 순서

1. **교사 화면에 로그인**합니다 (교사 계정 이메일과 비밀번호).
2. **명단 관리** 탭에서 학생이 등록되어 있는지 확인합니다. 처음이라면 [학생 등록](#학생-등록)을 먼저 합니다.
3. 위쪽 **평가 학급**에서 지금 평가할 학급을 고릅니다. 평가 시작·종료·다시 준비 버튼과 대시보드는 고른 학급에만 적용됩니다.
4. 학생들에게 학생 주소로 들어가 **학번과 비밀번호**로 로그인하게 합니다.
   - 처음 로그인하는 학생의 비밀번호는 `0000`이고, 로그인하자마자 새 비밀번호(숫자 4자리)를 정해야 합니다.
   - 로그인한 학생은 "평가 시작을 기다리고 있어요" 화면에서 기다립니다.
5. 대시보드에서 학생들이 **접속 중**으로 바뀌는 것을 확인한 뒤 **평가 시작**을 누릅니다. **그 학급** 학생 화면만 새로고침 없이 바로 평가 화면으로 바뀝니다. 다른 학급 학생은 대기 화면에 그대로 있습니다.
6. 평가하는 동안 대시보드를 봅니다 ([대시보드 보는 법](#대시보드-보는-법)).
7. 시간이 되면 **평가 종료**를 누릅니다.
   - 그 순간의 그 학급 학생 상태가 **결과 보기** 탭에 "2-3반 · 회차"로 저장되고, 그 학급 학생은 더 이상 입력할 수 없습니다.
   - 제출하지 않은 학생도 마지막으로 저장된 내용이 결과에 남습니다.
8. **결과 보기** 탭에서 회차를 골라 확인하고 **CSV 내려받기**로 엑셀 파일을 받습니다.
9. 다음 학급 시간에는 **평가 학급**만 바꿔서 3번부터 반복합니다. 학급마다 따로 시작·종료되므로 여러 학급이 동시에 진행되어도 서로 영향이 없습니다.
10. 같은 학급을 처음부터 다시 평가해야 할 때만 그 학급을 고르고 **다시 평가 준비**를 누릅니다.
   - 그 학급 학생들의 진행 기록과 접속 기록만 지워집니다.
   - 다른 학급, 명단, 학생 비밀번호, 이미 저장된 결과는 그대로 남습니다.

> 평가 상태는 학급마다 `대기 → 진행 중 → 종료 → (다시 평가 준비) → 대기` 순서로만 바뀝니다. 지금 누를 수 없는 버튼은 흐리게 보입니다. 학급이 2개 이상이면 학급별 상태가 칩으로 표시되고, 칩을 누르면 그 학급으로 바뀝니다. **전체 보기**에서는 버튼이 잠깁니다.

## 학생 등록

**명단 관리** 탭에서 합니다. 학번은 5자리(학년 1 + 반 2 + 번호 2)입니다. 예를 들어 `20301`은 2학년 3반 1번입니다. 학생 이름은 저장하지 않습니다.

- **반 단위로 한꺼번에**: 학년, 반, 번호 범위를 정하고 **범위 추가**를 누릅니다. 예를 들어 2학년 3반 1~30번이면 `20301`~`20330`이 만들어집니다.
- **붙여넣기로 추가**: 엑셀의 학번 열을 복사해 붙여넣습니다. 줄바꿈, 쉼표, 공백, 탭 모두 구분자로 인식합니다. 추가될 인원, 이미 등록된 학번, 형식 오류가 미리 표시됩니다.
- **한 명 추가**: 학번을 입력하고 추가합니다.

새로 추가한 학생의 비밀번호는 모두 `0000`입니다. 이미 등록된 학번은 건너뛰므로 같은 범위를 다시 추가해도 기존 학생의 비밀번호는 바뀌지 않습니다.

**삭제**: 학번 옆의 ×나 **반 전체 삭제**를 누릅니다. 명단, 비밀번호, 진행 기록이 지워지고, 그 학번으로 로그인해 있던 학생은 로그인 화면으로 돌아갑니다. 이미 저장된 평가 결과는 지워지지 않습니다.

## 대시보드 보는 법

학생마다 카드 하나가 나옵니다. 위쪽 요약에서 전체 인원, 접속 중, **지금 이탈 중**, 제출, 수정 중, 단계별 인원을 한눈에 봅니다.

| 카드 색 | 뜻 |
|---|---|
| 흰색 · 초록 점 **집중** | 평가 화면을 보고 있음 |
| 빨간 테두리 · 깜박이는 점 **이탈 중** | 다른 탭이나 창으로 이동해 있음 |
| 노란색 **응답 없음** | 접속은 되어 있는데 90초 넘게 신호가 없음 (기기 절전, 네트워크 문제 등) |
| 회색 **오프라인** | 접속하지 않았거나 창을 닫음 |
| 초록색 **✓ 제출** | 제출 완료 |
| **수정 중** 배지 | 한 번 제출한 뒤 수정하기를 눌러 고치는 중 (다시 제출해야 제출 완료) |

- **이탈 횟수, 이탈 시간**: 평가가 진행 중일 때 다른 탭이나 창으로 이동한 횟수와 그 시간의 합계입니다. 대기 중에는 세지 않습니다. **제출을 마친 학생**은 '이탈 중' 상태는 보이지만 횟수와 시간은 늘지 않습니다. 그 학생이 수정하기를 누르면 다시 셉니다.
- **붙여넣기 횟수**: 평가 화면의 입력칸에 붙여넣은 횟수입니다. 막지는 않고 기록만 합니다.
- 학생들은 대기 화면에서 "다른 탭으로 이동하거나 붙여넣으면 선생님 화면에 표시돼요"라는 안내를 봅니다.
- 대시보드는 위에서 고른 **평가 학급**만 보여 줍니다 (전체 보기를 고르면 모든 학급). **정렬**(학번순 / 단계 낮은 순 / 이탈 많은 순), **지금 이탈 중인 학생만** 보기를 쓸 수 있습니다.
- **상세**를 누르면 그 학생의 모델 이름, 학습 데이터, 테스트 결과, 윤리 서술을 실시간으로 볼 수 있습니다.

## 교사 계정 접속 기록

로그아웃 옆 **접속 기록**을 누르면 교사 계정이 언제, 어느 IP와 기기에서 교사 화면에 들어왔는지 볼 수 있습니다. 맨 위에는 지금 접속을 뺀 **이전 접속**이 크게 나옵니다.

- 교사 화면에 들어올 때마다 기록되고, 최근 30개만 보관합니다. 같은 탭에서 새로고침할 때는 다시 기록하지 않습니다.
- 모르는 시각이나 IP가 있으면 다른 사람이 교사 계정으로 들어온 것일 수 있으니 교사 계정 비밀번호를 바꾸세요.
- IP는 공개 IP 확인 서비스(api64.ipify.org 등)에 물어서 얻습니다. 학교 안에서는 여러 기기가 같은 IP로 보일 수 있고, 서비스에 연결되지 않으면 '알 수 없음'으로 남습니다.

## 비밀번호를 잊은 학생

학생 카드의 **비밀번호 초기화**를 누릅니다.

- 비밀번호가 `0000`으로 돌아가고, 학생은 다시 로그인하면서 새 비밀번호를 정합니다.
- 그 학생이 다른 기기에 로그인해 있었다면 자동으로 로그아웃됩니다.
- **작성 중이던 답안은 지워지지 않습니다.** 다시 로그인하면 이어서 할 수 있습니다.

## 학생 화면에서 일어나는 일

- **자동 저장**: 글을 쓰는 동안 2초마다, 단계를 넘길 때는 바로 저장됩니다. 화면 위쪽에 "저장됨 · 시각"이 표시됩니다. 새로고침하거나 기기를 바꿔 다시 로그인해도 저장된 단계부터 이어서 합니다.
- **데이터 입력**: 클래스 2~6개, 클래스마다 문장 5~30개(쉼표로 구분), 문장 하나는 100자 이하입니다.
- **테스트**: 저장되지 않는 자유 테스트와, 제출용 테스트 문장 3개가 있습니다. 3개 모두 분류해야 다음으로 넘어갑니다. 데이터를 고쳐 다시 학습하면 3개의 결과가 새 모델로 자동으로 다시 계산됩니다.
- **윤리 서술**: 항목마다 50자 이상 써야 제출할 수 있습니다.
- **제출 후 수정**: 평가가 종료되기 전까지는 **수정하기**로 다시 고쳐 제출할 수 있습니다.

**CSV 내려받기**를 누르면 엑셀에서 바로 열 수 있는 파일(`ai_ethics_학급_회차.csv`)을 받습니다. 반 필터를 고른 상태라면 그 반만 받습니다.

**이 결과 삭제**는 되돌릴 수 없으니 먼저 CSV를 받아 두세요.

## 알아 둘 점

- **비밀번호는 4자리 숫자**입니다. 보안 규칙이 학번마다 로그인 시도 사이에 3초 이상을 강제해서, 한 학번의 비밀번호를 모두 대입하려면 8시간 넘게 걸립니다. 수업 시간 안에서 쓰는 수준의 보호입니다. 비밀번호는 암호화(해시)되어 저장되므로 교사도 학생의 비밀번호를 볼 수 없습니다.
- **같은 브라우저에서 교사와 학생으로 동시에 로그인할 수 없습니다.** 같은 주소에서 교사로 로그인하면 그 브라우저의 학생 로그인이 풀립니다. 수업에서는 교사와 학생이 서로 다른 기기를 쓰므로 문제가 없습니다.
- **학생 로그인은 탭 단위**입니다. 새로고침해도 유지되지만, 탭이나 브라우저를 닫거나 새 탭을 열면 다시 로그인해야 합니다. 공용 크롬북에서 다음 사람이 이전 학생으로 로그인된 채 시작하지 않게 하려는 것입니다. 그래도 끝나면 **로그아웃**을 누르게 해 주세요.
- 학생 이름은 수집하지 않습니다. 이름이 필요하면 CSV를 받아 학교 명단과 학번으로 맞춰 주세요.
- 무료 Firebase 요금제는 **동시 접속 100명**까지입니다. 한두 반이 동시에 평가하기에는 충분합니다.

## 관리자용: 설치와 설정

이 사이트는 GitHub Pages(정적 파일)와 Firebase(Realtime Database, Authentication)로 동작합니다. 서버 코드는 없고, 모든 권한 검사는 Firebase 보안 규칙이 합니다.

### Firebase 설정 (처음 한 번)

1. Firebase 콘솔에서 프로젝트를 만듭니다 (현재: `ai-ethics-3bb57`).
2. **Realtime Database**를 만듭니다 (위치: 싱가포르 `asia-southeast1`, 잠금 모드로 시작).
3. **Authentication → 로그인 방법**에서 **익명**과 **이메일/비밀번호**를 켭니다.
4. **Authentication → 사용자**에서 교사 계정을 만듭니다.
5. **프로젝트 설정 → 내 앱**에서 웹 앱을 등록하고, 나오는 `firebaseConfig` 값을 [js/firebase-config.js](js/firebase-config.js)에 넣습니다. 같은 파일의 `TEACHER_EMAIL`도 교사 계정 이메일로 바꿉니다.
6. [database.rules.json](database.rules.json)과 [js/firebase-config.js](js/firebase-config.js)의 교사 uid를 교사 계정의 uid로 바꾼 뒤(Authentication → 사용자에서 확인), 규칙 내용 전체를 **Realtime Database → 규칙**에 붙여넣고 **게시**합니다.

> `database.rules.json`을 고치면 **반드시 콘솔에 다시 게시**해야 적용됩니다. 저장소의 파일만 바꿔서는 적용되지 않습니다.

### 교사 계정 비밀번호를 잊었을 때

교사 이메일이 실제로 받을 수 있는 주소라면 Firebase 콘솔의 **Authentication → 사용자**에서 비밀번호 재설정 메일을 보냅니다. 받을 수 없는 주소라면 같은 이메일로 사용자를 지우고 다시 만듭니다.

### 로컬에서 미리 보기

```bash
node tools/serve.mjs
```

`http://localhost:8000/`(학생)과 `http://127.0.0.1:8000/teacher.html`(교사)을 엽니다. 두 주소를 다르게 쓰면 한 브라우저에서 교사와 학생으로 동시에 로그인해 시험할 수 있습니다. ES module을 쓰기 때문에 HTML 파일을 더블클릭해서(`file://`) 열면 동작하지 않습니다.

[tools/seed-test.json](tools/seed-test.json)은 빈 데이터베이스에 가짜 학생(`10101`, 비밀번호 `0000`)을 넣는 시험용 파일입니다. 콘솔의 **JSON 가져오기**는 데이터베이스 전체를 덮어쓰므로 실제 데이터가 있을 때는 쓰지 마세요.

### 파일 구성

설계 전체는 [spec.md](spec.md)에, 작업 규칙은 [CLAUDE.md](CLAUDE.md)에 있습니다.

| 파일 | 역할 |
|---|---|
| `index.html`, `js/student.js` | 학생 화면: 로그인, 비밀번호 변경, 대기·종료 화면 |
| `js/exam.js` | 학생 평가 1~5단계, 자동 저장, 제출·수정 |
| `js/presence.js` | 학생 접속·이탈·붙여넣기 기록 |
| `js/classifier.js` | 나이브 베이즈 텍스트 분류기 (학생 브라우저에서 학습) |
| `teacher.html`, `js/teacher.js` | 교사 화면: 로그인, 평가 제어, 대시보드 |
| `js/roster.js`, `js/results.js`, `js/detail.js` | 명단 관리, 결과 보기·CSV, 학생 상세 |
| `js/common.js`, `js/firebase.js`, `js/firebase-config.js` | 공통 기능과 Firebase 연결 |
| `css/style.css`, `css/teacher.css` | 스타일 |
| `database.rules.json` | Firebase 보안 규칙 (콘솔에 게시해야 적용) |
